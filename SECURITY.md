# Security

BunjiBox is a LAN-only alpha. Its web development server has no user or device
authentication and can let a connected person run commands through an agent.
Use it only on a trusted network. Do not expose it to the public internet.

For a vulnerability, [report it privately through GitHub Security](https://github.com/bakerheit/BunjiBox/security/advisories/new).
Please do not post exploit details, keys, or private data in a public issue.

Include the affected version or commit, steps to reproduce, impact, and any
suggested fix. There is no fixed response or release schedule yet.
